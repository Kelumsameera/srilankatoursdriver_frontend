# Editorial image assets

These eight images were created with OpenAI image generation for this project. They are illustrative visuals, not documentary photographs; landmark details may not be exact. The vehicle banner is visibly labeled as illustrative, and all CMS-uploaded imagery takes precedence over local fallbacks.

Each image is provided as WebP at 640 px, 1080 px, and its generated full width. The `640` and `1080` variants are selected by `localImageUrl` in `src/lib/cloudinary-loader.ts`.

| Base filename | Intended use |
|---|---|
| `hero-sri-lanka-landscape` | Homepage hero fallback |
| `destination-sigiriya` | Sigiriya destinations and related tours |
| `destination-ella-nine-arch-bridge` | Ella and hill-country destinations and tours |
| `destination-kandy` | Kandy destinations and related tours |
| `destination-mirissa` | Southern coast destinations and related tours |
| `destination-yala-elephant` | Yala and wildlife destinations and related tours |
| `private-driver-scenic-road` | Tailor-made travel editorial section fallback |
| `vehicle-private-transfer-illustrative` | Vehicles listing page banner only; not a specific fleet vehicle |

The full-resolution PNG originals remain in this machine's Codex generated-images directory. The app serves only optimized WebP variants from this folder.
